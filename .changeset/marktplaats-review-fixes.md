Harden the Marktplaats MCP after Codex review, before its first release. The per-IP rate limiter is now charged for each upstream read a tool performs rather than once per call, so a place-resolving search (two PDOK reads plus one Marktplaats read) and a multi-hop listing fetch stay within the documented 30-reads-per-minute bound while a fully cached call still costs nothing. A search served from the 60-second cache now reports `observedAt` at the earliest instant its snapshot could have been fetched, so a watcher advancing its `postedSince` cursor can no longer skip a listing posted during the cache window. The accessible result window is capped so `offset + limit` may not exceed 100, matching the personal-use ceiling the docs name, instead of paging to 300. A listing redirect must land on the canonical path for the requested id, so a redirect to another advert is refused instead of returned under the asked id. Malformed search and PDOK envelopes are reported as `upstream_unavailable` rather than an empty result or an unknown place; a capped listing description and a description that fell back to the page summary both set `descriptionTruncated`; over-long attribute text is bounded so a listing can no longer fail its own schema; an open-ended price range with a very high minimum no longer reverses; the `window.__CONFIG__` reader requires the real assignment so seller-controlled page text cannot capture it; and the image inspector enforces its 2 MiB cap while streaming so a mis-declared Content-Length cannot exhaust the agent.
